# Происхождение

Производный исследовательский проект из https://github.com/e-shchukin/DigitalTwinSync

Исходный коммит: `763aae5ee00912d2c4c484dfc3d931b2cfbfcb3c`. История исходного репозитория сохранена.

Формат протокола v2 несовместим с исходной строковой сериализацией: бинарные поля имеют однозначное кодирование, тип сообщения проверяется при приёме. Новый эксперимент представляет отдельную серию и не воспроизводит старые числа по определению.
