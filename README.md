# Программа моделирования и оценки защищённой синхронизации состояния цифрового двойника

Экспериментальный программный стенд для моделирования обмена между источником данных и цифровым двойником, проверки целостности состояния и оценки обнаружения нарушений синхронизации.

Версия: 1.0.0.

## Возможности

- аутентификация сообщений с помощью HMAC-SHA-256;
- контроль эпохи и последовательности обновлений;
- проверка результирующего состояния по SHA-256;
- периодическая проверка согласованности состояний;
- восстановление состояния по аутентифицированному контрольному снимку;
- моделирование восьми сценариев нарушения обмена;
- сравнение трёх вариантов защиты;
- расчёт показателей обнаружения, потери связи и восстановления;
- веб-интерфейс и HTTP API для запуска экспериментов.

## Сценарии эксперимента

1. Модификация сообщения обновления.
2. Повтор ранее принятого сообщения.
3. Удаление промежуточного обновления.
4. Удаление последнего обновления.
5. Повреждение локального состояния цифрового двойника.
6. Откат контрольного снимка.
7. Повтор контрольного снимка из предыдущего сеанса.
8. Полное подавление канала связи.

## Требования

- .NET 8 SDK;
- Windows, Linux или macOS;
- современный веб-браузер.

## Запуск

```bash
dotnet restore
dotnet run
```

После запуска адрес веб-интерфейса выводится в консоль. Документация API доступна по пути `/swagger`.

## API

- `GET /health` - проверка доступности приложения;
- `GET /api/experiment/defaults` - параметры эксперимента по умолчанию;
- `GET /api/experiment/run-default` - запуск с параметрами по умолчанию;
- `POST /api/experiment/run` - запуск с переданными параметрами.

## Назначение

Программа предназначена для исследовательского моделирования и оценки алгоритмов защищённой синхронизации. Она не предназначена для непосредственного управления промышленным оборудованием.
